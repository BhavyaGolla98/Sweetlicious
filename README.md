🍬 Sweetlicious – Secure E-Commerce Website

Sweetlicious is a secure e-commerce platform for handcrafted confectionery and savory delights. It connects talented chefs with a wider audience while ensuring strong security and a seamless shopping experience.

🚀 Key Features

User registration & login with Multi-Factor Authentication (MFA) (Google Authenticator + Backup Codes)

Product listings, search, wishlist, cart & checkout

Stripe Payment Gateway integration for secure payments

Notifications/alerts for user activity

Security protections: SSL, CSRF, SQL injection prevention, clickjacking protection, URL injection prevention

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript, AJAX

Backend: Python (Django MTV)

Database: SQLite

Payment Gateway: Stripe

🔐 Security Highlights

MFA with time-based OTP (valid 30s) & backup codes

CSRF tokens on all forms

SQL Injection prevention via Django ORM & escaping

Middleware for clickjacking & URL injection defense

📊 Results

Functional homepage & shop with secure flows

Smooth checkout with payment authentication

Tested against SQLi, CSRF, clickjacking & URL injection
